Naked Single

Beginner

A cell where only one number is possible. This is the most basic Sudoku technique.

Your Strategy:

  • 🔎 Scan each empty cell systematically
  • ✅ Cross off numbers already in the same row, column, and box
  • 💡 When only one number remains, you've found it!

Pro Tip: Start with cells that have the most neighbors filled in - they're easier to solve.

In this box, only 5 is missing from the sequence 1-9

2

Hidden Single

⭐ Easy

A number that can only go in one place within a row, column, or box, even if that cell has multiple candidates.

How it works:

  • Pick a number (e.g., 5)
  • Look at a row, column, or 3×3 box
  • If that number can only fit in one cell, place it there

Example: If 1 can only go in one cell of a box (blocked elsewhere), it must be 1.

1 is blocked from other cells, must go here

3

Full House

⭐ Easy

The Easy Win: When a region is almost complete with just one empty cell, the missing number is obvious.

Your Strategy:

  • 👀 Look for nearly complete rows, columns, or boxes
  • 🧮 Add up the numbers 1-9 and find what's missing
  • 🎉 Fill in the last number - instant satisfaction!

Pro Tip: This often happens near the end of a puzzle, creating a satisfying cascade of solutions.

Only 5 is missing from this row

Naked Pair

Intermediate

When two cells in a row, column, or box can only contain the same two numbers, those numbers can be eliminated from other cells.

How it works:

  • Find two cells with only the same two candidates (e.g., both can only be 3 or 7)
  • Remove those two numbers from all other cells in that row/column/box
  • This often reveals hidden singles or naked singles

Example: If two cells can only be {3,7}, no other cell in that unit can be 3 or 7.

3 and 7 are locked in C1 & C3, eliminating them from C2

5

Pointing Pair

Intermediate

When a candidate number in a box is restricted to one row or column, it can be eliminated from that row/column outside the box.

How it works:

  • Look for a number that appears only in one row/column within a 3×3 box
  • Eliminate that number from the rest of that row/column

Example: If 5 can only appear in row 1 of a box, eliminate 5 from the rest of row 1.

5 in Box 1 points to the right, clearing Row 1

6

Box/Line Reduction

Intermediate

When a candidate in a row/column is confined to one box, eliminate it from the rest of that box.

How it works:

  • Find a number that only appears in one box within a row/column
  • Remove that number from other cells in the box

This is the reverse of pointing pairs.

8 in Row 1 is confirmed for Box 1, clearing the rest of Box 1

Naked Triple

Advanced

When three cells in a unit can only contain the same three numbers, eliminate those numbers from other cells.

How it works:

  • Find three cells that collectively contain only three candidates
  • Each cell can have 2 or 3 of these candidates
  • Remove these three numbers from all other cells in the unit

Example: Cells with {1,2}, {1,3}, {2,3} form a triple. Remove 1, 2, and 3 from other cells.

1, 2, 3 are locked in the first three cells

8

X-Wing

Advanced

A pattern where a candidate appears in exactly two positions in two different rows (or columns), forming a rectangle.

How it works:

  • Find a number that appears in only 2 cells in each of 2 rows
  • If these 4 cells form a rectangle, eliminate that number from the columns they occupy
  • Also works with columns/rows reversed

Example: If 7 appears at (R1C2, R1C8) and (R5C2, R5C8), eliminate 7 from columns 2 and 8.

X-Wing forms a rectangle, clearing columns

9

Swordfish

Expert

An extension of X-Wing using three rows and three columns instead of two.

How it works:

  • Find a candidate that appears 2-3 times in each of 3 rows
  • If all occurrences align to only 3 columns, eliminate from those columns
  • Requires careful pattern recognition

This is a rare but powerful technique for expert-level puzzles.

Candidates align in 3 rows and 3 columns

10

XY-Wing

Expert

A chain of three cells with specific candidate patterns that allows elimination.

How it works:

  • Find a "pivot" cell with candidates {X,Y}
  • Find two "wing" cells: one with {X,Z} and one with {Y,Z}
  • The wings must see the pivot but not each other
  • Eliminate Z from any cell that sees both wings

Example: Pivot {3,7}, Wing1 {3,9}, Wing2 {7,9} → eliminate 9 from cells seeing both wings.
